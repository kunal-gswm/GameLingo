## 1. Executive Summary

Milestone **GL-036** (and sub-milestone **GL-036.1**) extends GameLingo with an enterprise-grade, read-only extraction and translation pipeline for packaged Ren'Py visual novels. Prior to this work, GameLingo recognized Ren'Py game directories but blocked extraction when games were packaged as `.rpa` archives containing compiled `.rpyc` scripts without loose `.rpy` source files.

GameLingo now safely inspects `.rpa` archives (RPA-3.0, RPA-2.0, RPA-1.0), extracts script members into an isolated workspace cache, decompiles `.rpyc` bytecode into readable Ren'Py script AST using pure-Python AST decompilation (`rpycdec==0.2.0`), extracts all translatable dialogue/narration/menus, and generates native non-destructive Ren'Py translation patches (`game/tl/<language>/strings.rpy`) with safe language activation (`game/gamelingo_activate.rpy`) without ever modifying the original game archives or source files.

The implementation was validated both against a comprehensive synthetic test suite (**160 tests passing locally**) and live against the actual packaged commercial game `island-1.0-win`.

## 2. GL-036.1 Bug Fixes & Reconciliations

### 2.1 RPA-1.0 Offset Calculation Fix
- **Root Cause:** In `create_synthetic_rpa()`, computing offsets for RPA-1.0 by estimating base offset from a dummy index dictionary led to an off-by-3 discrepancy under Python 3.12/Linux, as serializing real offsets changed the length of the zlib-compressed pickle blob compared to the placeholder. `read_member_bytes()` subsequently caught trailing zlib stream bytes instead of script content.
- **Resolution:** Implemented fixed-point iteration in `create_synthetic_rpa()` that recalculates chunk offsets until the compressed index length converges precisely with the recorded starting offsets. Added fallback stream decompression in `_parse_rpa_1()` using `zlib.decompressobj()`.
- **Validation:** `tests/unit/test_renpy_rpa.py::test_create_and_read_synthetic_rpa[RPA-1.0]` passes cleanly across both Python 3.12 and 3.14.

### 2.2 Activation Script Compatibility (`gamelingo_activate.rpy`)
- **Ren'Py Naming Rule:** Ren'Py reserves `00*` filenames exclusively for its internal system library scripts in `renpy/common/`. User or translation scripts starting with `00` violate Ren'Py engine conventions.
- **Renamed:** Updated `00_gamelingo_activate.rpy` to `gamelingo_activate.rpy` across the translation patch planner, application, staging, backup/restore, GUI preview and labels, CLI options, and tests.
- **Overwrite Safety Barrier:** Added a strict safety check in `apply_plan()`: if `game/gamelingo_activate.rpy` already exists and was not generated by GameLingo, patch application aborts immediately to avoid overwriting user-authored files.
- **Engine Semantics:** Validated against official Ren'Py translation documentation. Uses `config.default_language = "<language>"` in an `init python:` block alongside `default preferences.language = "<language>"`, preserving user settings while activating translations on visual novels without built-in language selectors.

### 2.3 False Source Requirement Warning Fix (GL-036.2)
- **Root Cause:** In `DashboardPage.on_select_game()`, game selection used `has_source_scripts` alone to decide whether to display a "Source Scripts Required" warning dialog. For games with archived `.rpyc` scripts where readable `.rpy` files were absent but `has_extractable_scripts` was `True`, this caused a false warning dialog to appear even though extraction was available.
- **Resolution:** Updated `on_select_game()` to check `has_source_scripts or has_extractable_scripts`. When compiled scripts and decompiler are available, the game selects normally with an informational dialog without describing the game as source-required. Corrupt archives, missing scripts, and unavailable decompiler cases retain the required warning. Updated `app.py` CLI extraction check consistently.
- **Validation:** Added 5 GUI regression tests verifying loose `.rpy`, archived `.rpyc` with decompiler, no extractable scripts, decompiler unavailable, and RPG Maker selection. Verified live against `island-1.0-win`.

## 4. Architecture & Security Implementation

### 4.1 Dedicated Read-Only RPA Reader (`src/gamelingo/adapters/renpy_rpa.py`)
- **Format Support:** Full read support for **RPA-3.0**, **RPA-2.0**, and **RPA-1.0**.
- **Pickle Security Barrier (`SafeRPAUnpickler`):** Restricted `pickle.Unpickler` subclass allowing only safe primitive data types (`bytes`, `str`, `int`, `float`, `bool`, `tuple`, `list`, `dict`, `set`, `frozenset`, `_codecs.encode`, `__builtin__.bytes`). Unauthorized classes, callables, or execution primitives (`os.system`, `subprocess`, `eval`) trigger `pickle.UnpicklingError`.
- **Path Traversal Protection:** `validate_member_path()` rejects directory traversal components (`..`), absolute paths, Windows drive letters, leading slashes, and null bytes (`RPAPathTraversalError`).
- **Offset & Bounds Checking:** Index offsets and chunk lengths are validated against archive file size before reading.
- **Selective Script-Only Extraction:** Bypasses images, audio, video, and fonts to avoid memory and disk overhead.
- **Workspace Cache Isolation:** Extracted members and decompiled sources are placed strictly in GameLingo's local workspace cache (`cache/renpy_work/...`), never in the game directory.

### 4.2 Decompiler Integration (`src/gamelingo/adapters/renpy_decompiler.py`)
- **Engine Selected:** Pure-Python `rpycdec==0.2.0` (MIT License). Attributed in `THIRD_PARTY_NOTICES.txt`.
- **Architecture:** Safely parses Ren'Py 7 & 8 AST structures without invoking external subprocesses or launching the game executable.
- **Deterministic Precedence:**
  1. Loose `.rpy` (game folder)
  2. Loose `.rpyc` (game folder)
  3. Archived `.rpy` (inside `.rpa`)
  4. Archived `.rpyc` (inside `.rpa`)

### 4.3 Translation Patch Planning (`src/gamelingo/patching/planner.py`)
- Respects native Ren'Py non-destructive translation mechanisms:
  - Generates `game/tl/<language>/strings.rpy` with `translate <language> strings:` blocks.
  - Generates optional `game/gamelingo_activate.rpy` configuring `config.default_language = "<language>"`.
  - Original scripts and archives are **never modified or rewritten**.
