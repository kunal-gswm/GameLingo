## 1. What is GameLingo?

GameLingo is a local-first, zero-subscription Windows desktop application and CLI designed for translating Japanese games into playable localized releases.

### Intended Beta Audience
- **Game Localizers & Fan Translators:** Translators who need structured string extraction, glossaries, translation memory, and Excel/CSV interchange without breaking in-game control codes.
- **Visual Novel & RPG Enthusiasts:** Players and modders translating Japanese Ren'Py visual novels or RPG Maker titles for personal enjoyment.
- **Quality Reviewers:** Editors who need split-view translation review, warning checks for broken escape tokens, and safe round-trip patch deployment.

## 2. The Golden Rule of Game Testing

> [!CAUTION]
> **ALWAYS TEST GAMELINGO ON A DEDICATED COPY OF YOUR GAME!**  
> Never point GameLingo directly at your primary game archive, your only copy, or an active Steam / DLsite installation directory.
> 
> 1. Copy the game folder into a test directory (e.g. `C:\GameTesting\Game_Copy\`).
> 2. Confirm the copy launches and plays in original Japanese.
> 3. Point GameLingo to `C:\GameTesting\Game_Copy\`.
> 4. Keep the original game folder completely untouched as your permanent baseline.

## 4. Engine Compatibility & Verification Tiers

GameLingo enforces an evidence-based distinction between engine compatibility levels:

| Engine Family | Source Formats | Patch Output | Verification Status | Notes |
| :--- | :--- | :--- | :--- | :--- |
| **RPG Maker MZ** | `data/*.json` | Serialized JSON | **Live-Runtime Verified** | Tested end-to-end against live engine runtime with rendered dialogue and screenshot capture (Pilots 1–7). |
| **Ren'Py (7.x / 8.x)** | `game/**/*.rpy`, `.rpa`, `.rpyc` | `game/tl/<lang>/strings.rpy` | **Live-Runtime Verified** | Tested against live Ren'Py engine processes with native string translation and fallback hooks. |
| **RPG Maker MV** | `data/*.json`, `www/data/*.json` | Serialized JSON | **Format & AST Verified** | Tested via syntax-tree parsing, serialization fidelity, and round-trip checksums. Live runtime untested. |
| **RPG Maker VX Ace** | `Data/*.rvdata2` | Ruby Marshal 4.8 | **Format & AST Verified** | Pure-Python Ruby Marshal parsing and IVAR round-trip verified. Live runtime untested. |
| **RPG Maker VX** | `Data/*.rvdata` | Ruby Marshal 4.8 | **Format & AST Verified** | Ruby Marshal parsing with CP932 encoding round-trip verified. Live runtime untested. |
| **RPG Maker XP** | `Data/*.rxdata` | Ruby Marshal 4.8 | **Format & AST Verified** | RGSS1 Ruby Marshal parsing and round-trip verified. Live runtime untested. |
| **RPG Maker 2003** | `*.ldb`, `*.lmt`, `*.lmu` | LCF Binary | **Format & AST Verified** | LCF binary format parsing and round-trip verified. Live runtime untested. |

> [!NOTE]
> Encrypted assets (`.rpgmvp`, `.rpgmvm`, `RGSS3A`, `RGSS2A`, `RGSSAD`) must be extracted/decrypted using third-party utilities prior to translation. GameLingo does not bypass encryption or DRM.

## 5. System Requirements & External Dependencies

- **Operating System:** Windows 10 (64-bit) or Windows 11 (64-bit).
- **Architecture:** x86_64.
- **Runtime Dependency:** Microsoft Visual C++ 2015–2022 Redistributable (x64). Pre-installed on most standard Windows installations. If a missing `vcruntime140.dll` error occurs, install the official Microsoft redistributable.
- **No Python Required:** The portable executable is self-contained. No Python, Git, or package managers are needed on the user's system.
- **Windows SmartScreen Notice:** Because GameLingo is an open-source project and beta binaries are not signed with a paid commercial code-signing certificate, Windows SmartScreen may show an alert on first launch (*"Windows protected your PC"*). Click **More info** $\rightarrow$ **Run anyway** after verifying the release source and checksum.

## 6. Offline Translation Model Notice

GameLingo features integrated offline neural machine translation powered by Argos Translate / CTranslate2.

> [!IMPORTANT]
> **Pre-trained models are not pre-installed in the portable binary.**  
> Neural translation models are large binary files (100MB–500MB) that are not bundled into the initial 124MB download:
> - On initial setup, connect to the internet, open **Settings** $\rightarrow$ **Translation Models**, and download the Japanese-to-English package.
> - Once downloaded, all subsequent translation jobs run completely offline without internet connectivity.
> - Alternatively, users can export translatable text to CSV, edit in external tools, and import back into GameLingo.

## 7. Reporting Bugs Safely (Protecting Game Copyright)

If you encounter an issue during testing, please submit a report using the [GitHub Beta Bug Report Template](https://github.com/kunal-gswm/GameLingo/issues/new?template=beta_bug_report.md).

> [!CAUTION]
> **DO NOT upload commercial game data, copyrighted images, proprietary scripts, or game archives to GitHub issues.**
> - Use generic synthetic examples (e.g. `"Hero: Hello \C[1]World\C[0]"`).
> - Sanitize local username paths (e.g. replace `C:\Users\JohnDoe\...` with `C:\Users\<User>\...`).
